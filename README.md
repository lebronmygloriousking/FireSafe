# FireSafe

FireSafe is a California wildfire safety and preparedness web app created for the Congressional App Challenge.

## Current version

**v1.2** — competition-focused update with a live safety pulse, preparedness snapshot, and personal readiness dashboard.

## Main features
- Current wildfire incident search
- California wildfire map
- Incident details and app risk indicator
- Official wildfire-relief organization links
- Measurable preparedness and environmental actions
- Local progress tracking with browser localStorage
- Responsive dashboard interface

## Run
Open `FireSafe.html` in a browser. Live wildfire and location searches require an internet connection.

## Important
FireSafe is an informational and preparedness tool. Users should verify evacuation orders, warnings, and emergency instructions with official local authorities and CAL FIRE.
